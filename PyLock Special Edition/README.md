# PyLock Special Edition

The enhanced version of PyLock with an interactive terminal interface using Questionary.

## Features

- Interactive terminal interface
- Custom password length
- Selectable character types
- Uppercase and lowercase letters
- Numbers
- Symbols

## Requirements

- Python 3.x
- Questionary

## Installation

Install the required dependency with:
```bash
python3 -m pip install -r requirements.txt
```

## Usage

Run the program with:

```
python3 PyLock-se.py
```


Follow the prompts in the terminal to configure the generated password.
