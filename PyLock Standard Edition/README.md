# PyLock Standard Edition

The lightweight version of PyLock using only Python's standard library.

## Features

- Custom password length
- Uppercase and lowercase letters
- Numbers
- Symbols
- No external dependencies

## Requirements

- Python 3.x

## Usage

Run the program with:

```bash
python3 PyLock-standard.py
```

Enter the desired password length when prompted.

Example:

```
Password length: 16
Password: K7#mQ2!xLp9@Kv4#
```
