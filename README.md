# PyLock

A simple password generator written in Python.

## Editions

### Standard Edition

A lightweight version using only Python's standard library.

- No external dependencies
- Simple terminal interface
- Uses Python's `random` module

[Go to Standard Edition](Standard/)

### Special Edition

An enhanced version with an interactive terminal interface using Questionary.

- Interactive prompts
- Password length selection
- Character type selection
- Uses Questionary for the terminal interface

[Go to Special Edition](Special-Edition/)

## Requirements

### Standard Edition

- Python 3.x
- No external dependencies

### Special Edition

- Python 3.x
- Questionary
